MycoScope — Diagnostic Specimen Workbench

HOW TO OPEN
1. Unzip the folder.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. Click any photo to inspect the original-resolution image.
4. Mouse wheel zooms, click-drag pans, double-click fits, 100% shows native pixel scale, Original opens the source image in its own tab.

HOW TO EXPAND
- Add original photos to assets/originals/.
- Add matching thumbnails to assets/thumbs/.
- Add specimen records and image entries in data.js.
- The display is generated automatically from those records.

WHY THIS FORMAT
- No Google Drive dependence.
- Original-resolution images remain separate and intact.
- Each picture can be zoomed and panned independently.
- Specimen descriptions and completeness data remain searchable and standardized.
- This can later be hosted as a private/local web app, GitHub Pages site, or Render static site without redesigning the atlas.
